# Screenshot Bukti UTS

Folder ini disediakan untuk menyimpan bukti screenshot implementasi dan pengujian.

- Daftar file wajib ada di [`../LAPORAN.md`](../LAPORAN.md) bagian **Daftar Screenshot Wajib**.
- Checklist pengambilan bukti ada di [`../TESTING.md`](../TESTING.md) bagian **Uji Manual dan Bukti Laporan**.
- Ambil screenshot setiap kali satu fitur selesai; jangan menumpuk di akhir.
- Jangan menyertakan password, token, `.env`, atau data sensitif di screenshot.
- Gunakan nama file sesuai daftar (contoh: `01-struktur-modul.png`) agar mudah dirujuk di laporan.
